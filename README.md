# 🧩 Фото Пазл — Telegram Mini App (@fotopuzzle_bot)

Пазли з фото, стікерів, GIF і відео прямо в Telegram.

## Що є в грі
- 🗺️ **Кампанія** — 200 рівнів із зірками, рівні на час.
- 🧩 **Свій пазл** — надішли боту стікер / GIF / фото / відео, обери розмір 3×3…6×6, і пазл з’явиться в грі. Анімовані стікери й GIF рухаються прямо в деталях.
- ⚔️ **Арена** — онлайн-бої 1 на 1: рейтинговий і звичайний режими, ELO-рейтинг, ліги, бот, якщо суперника не знайшлось.
- 🗓️ **Сезони Арени** — щомісяця (за UTC) сезонний рейтинг стартує з 1000. Основний рейтинг і ліга не скидаються. Після сезону гравець при першому вході на Арену отримує монети: 🥇 1000 · топ-3 — 700 · топ-10 — 500 · топ-100 — 200 · кожен учасник — 50 (один раз на акаунт).
- 🤝 **Командні бої 2×2** за посиланням-запрошенням.
- 👥 **Друзі** — запрошення в друзі, дуелі з другом, профіль друга, приватні аватарки та імена (видно лише друзям).
- 🦊 **Герої** — 7 героїв із суперударами, прокачка сили, захисту й енергії.
- 🎁 **Кейси й майстерня** — за ігрові монети, з точними шансами. Реальних платежів немає.
- 🎨 **Персональні фони**, рамки, теми; 📋 щоденні завдання, серії, досягнення; 🔊 звук.
- 🔄 **Автооновлення** — гра сама перезавантажується на нову версію, коли гравець спокійно стоїть на головному екрані.
- 🕶️ Таблиці лідерів анонімні: замість імен — випадкові псевдоніми.

## Як влаштований код
Без збірки, чистий JS. Сторінку збирає `index.html`: він підключає **конкретні файли з папок `vN/`**. Кожна папка — це «латка» тієї версії, в якій файл востаннє змінювався. У репозиторії лежать лише ті файли, які реально підключені.

| Що | Файл |
|---|---|
| Дані: рівні, герої, ліги, досягнення | `v12/data.js` |
| Збереження (localStorage + Telegram CloudStorage) | `v5/store.js` |
| Прогрес, монети, XP | `v12/prog.js` |
| Медіа (фото / GIF / стікери) | `js/media.js` |
| Рушій пазла | `js/puzzle.js` |
| Звук | `v4/sound.js` |
| Інтерфейс, екрани, профіль | `v19/ui.js` |
| Арена + сезони | `v20/arena.js` |
| Аватарки | `v17/avatars.js` |
| Друзі та запрошення | `v18/social.js` |
| Бої 2×2 | `v5/team.js` |
| Кейси | `v11/cases.js` |
| Автооновлення | `v20/update.js` |
| Пазли з чату | `v13/queue.js` |
| Персональні фони | `v18/backgrounds.js` |
| Запуск | `v17/main.js` |
| Стилі (по черзі) | `v4/app.css`, `v8/app.css`, `v10/cases.css`, `v13/app.css`, `v16/app.css`, `v18/app.css` |

Сервер — функції Vercel у `api/`:
- `api/bot.js` — вебхук бота: медіа → кнопки «зібрати пазл», запрошення `/start f_… / d_… / t_…`;
- `api/media.js` — безпечний проксі файлів Telegram (токен не потрапляє в браузер);
- `api/arena.js` — пошук суперника, бої, ELO, ліги, сезони, таблиці лідерів, друзі, аватарки;
- `api/team.js` — бої 2×2; `api/queue.js` — пазли, надіслані в чат боту;
- `api/setup.js` — одноразове налаштування вебхука, кнопки меню й команд;
- `api/_lib/` — Redis (`kv.js`), Telegram (`tg.js`), утиліти, друзі, аватарки.

## Як випускати нову версію
1. Скопіюй файл, який змінюєш, у нову папку `vN+1/` (наприклад, `v19/ui.js` → `v21/ui.js`) і правь копію.
2. У `index.html` заміни шлях на новий.
3. Створи `vN+1/update.js` (копія попереднього з `VERSION='N+1'`), підключи його в `index.html` і запиши `{"version":"N+1"}` у `version.json`. Тоді гравці, в яких гра відкрита, автоматично отримають оновлення.
4. Старий файл, якщо його більше ніде не підключено, видали.

## Перевірка перед випуском (гілка `dev`)
- Усі зміни спершу йдуть у гілку **`dev`**. Vercel сам робить для неї тестову копію (Preview) — посилання є у Vercel → Deployments або в Pull Request.
- Перевір тестову копію в браузері. Бот і гравці при цьому працюють зі старою версією.
- Коли все гаразд — Pull Request `dev` → `main`. Після злиття Vercel оновлює гру для всіх.
- ⚠️ Тестова копія користується тією ж базою Redis, тож рейтинг і друзі там справжні.

## Запуск на Vercel з нуля
1. **Add New → Project →** імпортуй цей репозиторій (Framework Preset: **Other**, без Build Command).
2. **Settings → Environment Variables:** `BOT_TOKEN` = токен від @BotFather; `SETUP_KEY` = довгий випадковий секрет; за потреби `APP_URL` = публічна адреса гри (власний домен).
3. **Storage → Upstash for Redis** (безкоштовний план) **→ Connect Project** — база для Арени, друзів і рейтингу.
4. **Deployments → Redeploy**.
5. Надішли POST на `https://<проєкт>.vercel.app/api/setup` із заголовком `X-Setup-Key: <SETUP_KEY>`. Бот отримає вебхук, кнопку меню «Грати» і команди. Секрет нікому не показуй.
6. За потреби в @BotFather → Bot Settings → Configure Mini App / Menu Button вкажи нову адресу.

> Без Redis гра працює, але Арена переходить в офлайн-режим (бої з ботом без рейтингу).

## Свідомо не зроблено
- **Публічна вітрина пазлів** прибрана: без платної модерації чужі фото публікувати небезпечно.
